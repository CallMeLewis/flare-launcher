# Name and icon

The code in this repository is free software under the GNU General Public License v3 (see [LICENSE](LICENSE)). The
licence covers the code. It does not cover the name **Flare Launcher** or the flare icon, which identify the official
launcher made by CallMeLewis.

## What you can do

- Build and run the launcher from this code, and change it for your own use.
- Share copies of the official, unmodified launcher under its own name.
- Say that your project is based on Flare Launcher, or works with it, in plain words.

## What needs a different name

If you share a modified version, give it a name and icon of its own, so nobody mistakes it for the official launcher.
Don't use "Flare Launcher", the flare icon or anything confusingly similar for it, and don't present it as official or
endorsed.

This is in line with section 7(e) of the GPL, which lets a licensor decline to grant rights to their names and marks.
