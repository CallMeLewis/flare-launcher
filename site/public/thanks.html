Thanks for downloading

Your download will start in a moment. If it doesn't, download it again.

Next steps

  1. Open the installer once it has downloaded.
  2. If Windows says it protected your PC, choose More info, then Run anyway. The installer isn't signed yet.
  3. Follow the installer, then open Flare Launcher from the Start menu.

Next steps

  1. Right-click the file, open Properties and allow it to run as a program: Executable as Program on Ubuntu, Is executable on KDE and Steam Deck.
  2. Double-click it to start.
  3. When it offers to add itself to your app menu, choose Add. From then on, open Flare Launcher from your app menu like any other app.

Or make it runnable from a terminal:

chmod +x Flare-Launcher-*.AppImage

Next steps

  1. Open the .deb file once it has downloaded. Your software centre opens: choose Install.
  2. Open Flare Launcher from your app menu.
  3. When an update installs, Linux asks for your password, as for any system update.

Or install it from a terminal, in the folder you downloaded it to:

sudo apt install ./Flare-Launcher-*-amd64.deb

Next steps

  1. Open the .rpm file once it has downloaded. Your software centre opens: choose Install.
  2. Open Flare Launcher from your app menu.
  3. When an update installs, Linux asks for your password, as for any system update.

Or install it from a terminal, in the folder you downloaded it to:

sudo dnf install ./Flare-Launcher-*.x86_64.rpm

Needs Steam with DayZ installed. The launcher keeps itself up to date.
