## Default Permission

Lets the window show the app's update status and check, download and install updates when the user asks.

#### This default permission set includes the following:

- `allow-status`
- `allow-check`
- `allow-download`
- `allow-install`
- `allow-settings`
- `allow-set-auto-check`
- `allow-set-channel`
